## 🎯 معرفی

این اپلیکیشن یک ابزار تحلیلی **فقط-خواندنی** است: هیچ کلید خصوصی، امضا یا سفارشی در کار نیست و
تنها از endpointهای عمومی (`/public/*`) صرافی Derive استفاده می‌کند.

کاری که انجام می‌دهد:

1. زنجیرهٔ آپشن فعال BTC یا ETH را برای سررسید انتخابی می‌گیرد (Bid/Ask/Mark/Greeks/IV).
2. برای **استراتژی انتخاب‌شده** (در هر لحظه فقط یکی) تمام ترکیب‌های معتبر استرایک‌ها را می‌سازد.
3. منحنی سود و زیان در سررسید، بیشترین سود، بیشترین زیان، نقاط سربه‌سر و سرمایهٔ درگیر را
   **پس از کسر کارمزد واقعی صرافی** محاسبه می‌کند.
4. نتایج را در یک جدول قابل مرتب‌سازی/فیلتر و یک نمودار تعاملی Chart.js نمایش می‌دهد و
   امکان خروجی گرفتن کارت تصویری ۱۰۸۰p برای اشتراک‌گذاری می‌دهد.

```text
مرورگر ──► Flask (app.py) ──► https://api.lyra.finance/public/*
   ▲             │
   └── JSON ◄────┘   (کش داخلی: ابزارها ۳۰۰s | تیکرها ۱۵s | اسپات ۵s)
```

## 🚀 شروع سریع

### پیش‌نیاز
- Python **۳.۹** یا بالاتر
- اتصال اینترنت به `api.lyra.finance`

### نصب و اجرا

```bash
# ۱) محیط مجازی (توصیه‌شده)
python -m venv .venv
source .venv/bin/activate        # ویندوز: .venv\Scripts\activate

# ۲) نصب وابستگی‌ها
pip install -r requirements.txt

# ۳) اجرا
python app.py
```

سپس مرورگر را باز کنید: **<http://localhost:5000>**

### متغیرهای محیطی

| متغیر | پیش‌فرض | توضیح |
|---|---|---|
| `PORT` | `5000` | پورت وب‌سرور |
| `FLASK_DEBUG` | `0` | `1` = حالت دیباگ (فقط برای توسعهٔ محلی) |
| `DERIVE_BASE_URL` | `https://api.lyra.finance` | آدرس API بالادستی (برای تست آفلاین) |
| `TEMPLATES_AUTO_RELOAD` | `0` | `1` = بارگذاری مجدد قالب بدون ری‌استارت |
| `MAX_COMBOS` | `30` | تعداد پیش‌فرض ترکیب‌ها به‌ازای هر استراتژی (سقف سخت: ۵۰۰) |

### اجرا در محیط عملیاتی

```bash
pip install gunicorn
gunicorn -w 2 -b 0.0.0.0:5000 app:app
```

> ⚠️ کش داخلی در حافظهٔ هر worker جداست؛ با تعداد worker بالا، تعداد درخواست به API صرافی زیاد می‌شود.

## 💵 مدل کارمزد Derive

محاسبات بر اساس [جدول رسمی کارمزدهای Derive](https://docs.derive.xyz/reference/fees-1) انجام می‌شود:

| ابزار | Taker | Maker |
|---|---|---|
| **آپشن** | `$0.50` (ثابت به‌ازای هر سفارش) `+ min(0.03% × نامینال , 12.5% × پریمیوم)` | `min(0.01% × نامینال , 12.5% × پریمیوم)` |
| **اسپات** | بدون کارمزد | بدون کارمزد |
| **پرپچوال** | `$0.10 + 0.03% × نامینال` | `0.01% × نامینال` |

که در آن `نامینال = قیمت اسپات × اندازهٔ قرارداد`.
**کارمزد پایهٔ ۰.۵ دلار ثابت است و با حجم معامله بزرگ نمی‌شود.**

### سه حالت اجرا (قابل انتخاب در تنظیمات)

| حالت | توضیح |
|---|---|
| **Taker** (پیش‌فرض) | هر لگ یک سفارش تهاجمی جداگانه → `$0.50` پایه **به‌ازای هر لگ** + جزء متغیر |
| **Maker** | سفارش لیمیت منتظر → `min(0.01% × نامینال, 12.5% × پریمیوم)` بدون کارمزد پایه |
| **RFQ** | یک مظنهٔ چندلگی: لگ‌ها به گروه‌های Long/Short Call/Put تقسیم می‌شوند؛ گران‌ترین گروه کامل، ارزان‌ترین **رایگان**، دومی و سومی **۵۰٪ تخفیف**، و فقط **یک** کارمزد پایه |

> مثال واقعی (Iron Condor روی ۰.۰۰۱ BTC): Taker ‏`$2.16` · RFQ ‏`$0.58` · Maker ‏`$0.04`

- کارمزد محاسبه‌شده از منحنی P&L کسر و به سرمایهٔ درگیر (Capital) اضافه می‌شود.
- تفکیک کارمزد هر لگ در جدول *Leg Details* و مجموع آن در مودال نمودار نمایش داده می‌شود.
- با کلید **Include Derive Trading Fees** در تنظیمات می‌توان محاسبهٔ کارمزد را خاموش کرد.

بررسی رابط کاربری بدون مرورگر (اختیاری، نیازمند `npm install jsdom`):

این اسکریپت (۲۴ بررسی) صفحه را در jsdom اجرا می‌کند و رندر جدول، انتخاب تک‌استراتژی،
پنجرهٔ نمودار، برچسب‌های موبایل و اثرات جانبی تنظیمات را می‌سنجد.

## ⚠️ محدودیت‌ها و نکات مهم

- **ابزار آموزشی/تحلیلی است، نه توصیهٔ سرمایه‌گذاری.** قیمت‌های واقعی اجرا با اسلیپیج و عمق بازار تفاوت دارند.
- محاسبات بر پایهٔ **سود و زیان در سررسید** است؛ ارزش‌گذاری میان‌دوره‌ای (Mark-to-Market) محاسبه نمی‌شود.
- قیمت‌گذاری هر لگ **قابل اجرا** است: خرید روی Ask و فروش روی Bid (با `use_mark_prices: true` می‌توان به Mark برگشت).
- سرمایهٔ نمایش‌داده‌شده تخمین محافظه‌کارانه است؛ برای عدد واقعی، دکمهٔ **«⚖️ Exchange margin»** در مودال
  نمودار مستقیماً از شبیه‌ساز مارجین خود صرافی (`public/get_margin`) می‌پرسد (SM یا PM2).
- تخفیف‌های کارمزد RFQ پشتیبانی می‌شود (حالت **RFQ** در تنظیمات)؛ پیش‌فرض محافظه‌کارانه **Taker** است.
- فهرست دارایی‌ها **پویا** از خود صرافی گرفته می‌شود (هر ارزی که بازار آپشن دارد)؛ زنجیرهٔ آپشن فقط برای دارایی انتخاب‌شده واکشی می‌شود.
- برای هر استراتژی حداکثر ۳۰ ترکیب تولید می‌شود.
